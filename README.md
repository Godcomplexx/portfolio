# Portfolio

Portfolio site for Daria Melnikova built with React, Vite, and Three.js.

## Scripts

- `npm install`
- `npm run dev`
- `npm run lint`
- `npm run build`
- `npm run preview`

## Local URLs

- Dev: `http://localhost:3000/portfolio/`
- Preview: `http://localhost:4173/portfolio/`

## Deployment

- GitHub repository: `https://github.com/Godcomplexx/portfolio`
- GitHub Pages URL: `https://godcomplexx.github.io/portfolio/`

## Project Files

- Resume HTML: `public/resume/daria_melnikova_resume_print.html`
- Resume download: `public/resume/Daria_Melnikova_CV.docx`
- Project media: `public/projects/`
- 3D lab media: `public/projects/3d/`
